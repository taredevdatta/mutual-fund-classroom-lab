# The Mutual Fund Classroom Lab

An interactive, India-focused introductory mutual fund learning resource for B.Com and M.Com classrooms.

## Files
- `index.html` — complete self-contained interactive resource.

## Run locally
Open `index.html` in any modern browser. No installation, account, API key, or internet connection is required.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **public** repository, for example `mutual-fund-classroom-lab`.
2. Upload `index.html` and this `README.md` to the repository's root folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for the deployment to finish. GitHub will show the public website URL in Settings → Pages. It usually follows:
   `https://YOUR-USERNAME.github.io/mutual-fund-classroom-lab/`
7. Open that URL in a private/incognito window to verify public access.

## Teaching use
Suggested duration: 60–90 minutes. Learners explore concepts, compare fund categories, build a hypothetical allocation, run assumed-return scenarios, and complete a five-question quiz. A teacher guide and learning outcomes are included in the page.

## Important educational disclaimer
All investor details, allocations, and return assumptions are hypothetical. The simulator is not connected to live market data and is not investment advice. Returns are not guaranteed. It excludes taxes, exit loads, inflation, changing market returns, and other real-world factors. Teachers should verify current regulatory and scheme information from SEBI, AMFI, and scheme documents before teaching current facts.

## Adaptation
Teachers may adapt the case study, language, amounts, questions, and learning sequence for their own classes. Keep the risk disclaimer visible when adapting or redistributing.
